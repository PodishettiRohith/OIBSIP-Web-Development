# Personal Portfolio

## Project Description

This project is a personal portfolio website designed to showcase a person's profile, skills, projects, and contact information. It works as a simple digital résumé and provides visitors with an overview of the developer's abilities and work.

## Technologies Used

* HTML5
* CSS3
* Google Fonts
* CSS Flexbox
* CSS Grid

## Features

* Profile/Hero section
* Name and professional role
* Profile image or avatar
* About Me section
* Skills section
* Projects section
* Project cards
* GitHub link placeholders
* Contact section
* LinkedIn and GitHub links
* Smooth scrolling navigation
* Responsive design
* Consistent colour scheme and typography

## How to Run

1. Open the project folder in Visual Studio Code.
2. Open `index.html`.
3. Right-click the file and select **Open with Live Server**, or open `index.html` directly in a web browser.

## Objective

To create a responsive personal portfolio website that presents profile information, technical skills, projects, and contact details in a professional layout.
