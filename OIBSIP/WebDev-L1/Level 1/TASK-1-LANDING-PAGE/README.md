# Nova - Landing Page

## Project Description

Nova is a modern and responsive landing page created for an AI productivity platform. The website presents the product, its features, benefits, user testimonials, and contact information in a clean and attractive design.

## Technologies Used

* HTML5
* CSS3
* Google Fonts
* CSS Flexbox
* CSS Grid

## Features

* Sticky navigation bar
* Hero section with headline and call-to-action button
* Features section
* About section
* Testimonials section
* Call-to-action section
* Footer with contact and social links
* Responsive design for mobile and desktop
* Consistent colour scheme and typography

## How to Run

1. Open the project folder in Visual Studio Code.
2. Open `index.html`.
3. Right-click the file and select **Open with Live Server**, or open `index.html` directly in a web browser.

## Objective

To build a visually polished static landing page while demonstrating basic HTML5 and CSS3 layout and responsive design skills.
