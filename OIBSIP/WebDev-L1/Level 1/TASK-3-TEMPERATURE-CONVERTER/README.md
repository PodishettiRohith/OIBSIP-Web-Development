# Temperature Converter

## Project Description

The Temperature Converter is an interactive web application that allows users to convert temperature values between Celsius, Fahrenheit, and Kelvin.

## Technologies Used

* HTML5
* CSS3
* JavaScript
* DOM Manipulation

## Features

* Temperature input field
* Celsius, Fahrenheit, and Kelvin unit selection
* Temperature conversion
* Convert button
* Converted result display
* Numeric input validation
* Error message for invalid input
* Absolute zero validation
* Clean and responsive user interface

## Conversion Formulas

* Celsius to Fahrenheit: `(C × 9/5) + 32`
* Fahrenheit to Celsius: `(F − 32) × 5/9`
* Celsius to Kelvin: `C + 273.15`
* Kelvin to Celsius: `K − 273.15`

## How to Run

1. Open the project folder in Visual Studio Code.
2. Open `index.html`.
3. Right-click the file and select **Open with Live Server**, or open `index.html` directly in a web browser.
4. Enter a temperature value.
5. Select the input unit.
6. Click the **Convert** button to view the result.

## Objective

To build an interactive temperature conversion tool using HTML5, CSS3, and vanilla JavaScript with input validation and user-friendly error handling.
